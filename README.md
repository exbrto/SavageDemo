# 21 Savage

A full-stack message board. Post a message, read what others have posted, 
like or dislike messages with a running count, and delete messages.

## Live Link

[21 Savage](https://savagedemo-1mj4.onrender.com/)

## Features

- Post a message
- Read messages from other users
- Like and dislike messages, with a counter for each
- Delete messages

## Built With

- HTML, CSS, JavaScript
- Node.js and Express
- MongoDB

## Installation

1. Clone the repo
2. Run `npm install`

## Usage

1. Run `npm run savage`
2. Go to `localhost:3000`
